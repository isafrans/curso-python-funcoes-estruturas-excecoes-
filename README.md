## 📋 Sobre o curso

Curso voltado para quem está iniciando na área de Data Science com Python. Aborda conceitos fundamentais como funções, estruturas de dados avançadas e tratamento de exceções, com foco em aplicações práticas para análise de dados.

- **Plataforma:** Alura  
- **Carga horária:** 8 horas  
- **Trilha:** [Python para Data Science](https://cursos.alura.com.br/formacao-data-science-python)  
- **Carreiras relacionadas:** Ciência de Dados · Análise de Dados · Engenharia de Dados · Governança de Dados  

---

## 📚 Conteúdo por módulo

### 1. 📦 Bibliotecas
- Importando e utilizando bibliotecas Python
- Uso de alias e importação de funções específicas
- PIP e PyPI
- Pacotes úteis para Data Science

### 2. 🔧 Funções
- Funções embutidas (*built-in*)
- Criando funções personalizadas
- Escopo de variáveis
- Funções com retorno e retorno múltiplo
- Desempacotamento de valores
- Documentando funções (*docstrings*)
- Funções **lambda** e uso com `map()`

### 3. 🗂️ Estruturas de Dados
- Lista de listas e indexação aninhada
- Tuplas e lista de tuplas
- **List comprehension** com `if-else`
- **Dict comprehension**
- Função `zip()`

### 4. ⚠️ Lidando com Exceções
- Tipos de exceções em Python
- Tratamento com `try/except`
- Cláusula `finally`
- Lançando exceções com `raise`
